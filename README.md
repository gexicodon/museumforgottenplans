# Музей несбывшихся планов

React + Vite + React Router (клиент), Express + SQLite (сервер). Данные в `data/museum-v3.db`.

## Запуск
    cp .env.example .env
    npm install
    npm run dev                                  # сайт :5173, API :3001
    npm run build && node --env-file=.env server/index.js   # продакшен на :3001
    docker compose up -d --build                 # или Docker

## Страницы
`/` главная, `/exhibition` экспозиция, `/idea/:id` идея, `/submit` сдать идею, `/halls` залы сходств, `/mix` сочетания, `/login`, `/register`, `/profile`.

## Аккаунты
Регистрация по имени, почте и паролю. Пароли хранятся как scrypt-хэш с солью, сессии лежат в SQLite (в куке только случайный токен, в базе его хэш; HttpOnly, SameSite=Lax, 30 дней). Читать могут все, писать, лайкать и обращаться к ИИ только вошедшие. Идею и продолжение можно публиковать анонимно, имя сохраняется в базе, но не показывается. Аккаунт с почтой из `ADMIN_EMAIL` становится модератором и может удалять любые идеи. Три жалобы от разных аккаунтов скрывают идею.

Старую базу `museum.db` версии 2 перенести нельзя: структура изменилась, файл `museum-v3.db` создаётся заново.
