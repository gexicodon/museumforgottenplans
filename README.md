# Музей несбывшихся планов

Курсовой проект об идеях, которые люди отложили и готовы передать другим. Посетитель может изучить экспозицию, посмотреть похожие замыслы, опубликовать свой экспонат и добавить продолжение к чужому.

## Запуск

Нужен Node.js 22.13 или новее. Все изображения и шрифты входят в проект. SQLite создаёт базу при запуске и добавляет демонстрационные экспонаты.

```bash
npm ci
npm run build
npm start
```

Готовый сайт работает на [localhost:3001](http://localhost:3001). Для разработки используйте `npm run dev` и откройте [localhost:4173](http://localhost:4173). Сборка и сервер работают без ключей и внешних API.

Для Docker скопируйте `.env.example` в `.env` и выполните `docker compose up --build`. Файл базы будет храниться в каталоге `data` на вашей машине.

## Сценарий демонстрации

1. Откройте экспозицию, выберите «Искусство» и найдите «Карту звуков исчезающих мест».
2. Зарегистрируйтесь и опубликуйте идею. Включите анонимность, если хотите скрыть имя в карточке.
3. Откройте другой экспонат, поставьте отклик и добавьте продолжение. Результат появится в карточке и личном кабинете.
4. Посмотрите залы сходств и попробуйте «Сочетания». Получившийся замысел можно сохранить как новый экспонат.

## Устройство проекта

- `src/` содержит страницы React, маршруты React Router и браузерный клиент API.
- `server/` содержит Express API, работу с SQLite и подбор похожих идей. Залы формируются по косинусному сходству слов из названий и описаний.
- Случайная пара берётся из разных разделов. Базовый вариант сочетания использует встроенный шаблон. Если указать `ANTHROPIC_API_KEY` и при необходимости `ANTHROPIC_MODEL` в `.env`, Claude предлагает названия залов и варианты сочетаний.
- Пароли хранятся как хэши scrypt с индивидуальной солью. Сессия хранится в SQLite, браузер получает HttpOnly cookie. Три жалобы от разных аккаунтов скрывают экспонат. Для новой учётной записи модератора укажите `ADMIN_EMAIL` и `ADMIN_SETUP_TOKEN` в окружении и введите этот код при регистрации.

## Перенос существующих данных

Формат `museum-v3.db` из исходного проекта поддерживается. Остановите сервер и сделайте резервную копию базы. Скопируйте её в `data/` и при наличии перенесите вместе с ней соответствующий файл `museum-v3.db-wal`. Затем запустите музей. Также можно указать путь к существующей базе через `DB_PATH` в `.env`. Формат старой базы `museum.db` версии 2 отличается.

Архив проекта содержит код и демонстрационное наполнение. При первом запуске создаётся новая база.
