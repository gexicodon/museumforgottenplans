# AI Project Architect

Architect помогает составить предварительный технический план выбранной идеи с учётом навыков, часов в неделю, бюджета и желаемого результата. План и вызовы показываются на отдельной странице; база не изменяется.

## Режимы и запуск

Установите зависимости и запустите `npm run dev`. Войдите в аккаунт, откройте «Архитектор», выберите идею, заполните поля и нажмите «Составить план». Для нулевого бюджета введите `0`.

Без `ANTHROPIC_API_KEY` приложение работает локально: пять MCP-инструментов вызываются по фиксированным правилам, без языковой модели. Это бесплатный способ проверить функцию. Результат явно отмечен как локальный и представляет собой шаблонную оценку.

Если на сервере задан `ANTHROPIC_API_KEY`, Architect использует Claude Messages API: модель выбирает инструменты и получает их результаты, после чего возвращает план. `ANTHROPIC_MODEL` необязателен: по умолчанию `claude-sonnet-5-5`. Ключ задаётся только в окружении сервера, не в исходном коде. Данные идеи, навыки, бюджет, время и результат передаются внешнему провайдеру; его использование может быть платным. При ошибке, недоступности, неверном ответе или превышении лимита отображается явно обозначенный локальный режим. Не передавайте чувствительные данные без учёта условий провайдера.

## Архитектура и ограничения

`POST /api/architect` принимает `ideaId`, `skills`, `hoursPerWeek`, `budget`, `outcome` и проверяет данные. `architect-agent.js` подключает MCP-сервер через клиент и получает список инструментов и их схемы. При работе с LLM она решает, какие инструменты вызвать; действительные результаты передаются в следующем сообщении и используются для плана. Допускается не более шести обращений к модели и восьми предложенных вызовов за цикл. Отдельный локальный резервный режим выполняет пять вызовов. История содержит только действительно переданные MCP вызовы и их статус; отклонённые до выполнения запросы модели туда не включаются.

Доступны только пять инструментов `analyze_feasibility`, `suggest_tech_stack`, `generate_mvp_plan`, `break_into_tasks`, `estimate_effort`. Они проверяют входные данные и структурированные результаты. Агент отклоняет неизвестные инструменты и изменённые моделью исходные параметры. Пользовательский текст считается недоверенными данными. Эти меры снижают риск внедрения инструкций, но не дают полной гарантии: проверяйте ответы модели и не передавайте им полномочия на реальные действия.

Для внешних MCP-клиентов `node server/architect-mcp.js` запускает отдельный сервер по stdio. Схемы доступны через `tools/list`. Оценки — приблизительные диапазоны для одного человека; стоимость, лицензии, сроки обучения и внешние согласования нужно проверять отдельно.

Проверки: `node --test tests/architect.test.js tests/architect-llm.test.js` и `npm run build`. Тесты модели используют mock и не требуют платного API. Реальное качество и доступность выбранной модели зависят от учётной записи провайдера.
